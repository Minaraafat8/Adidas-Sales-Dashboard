👟 Adidas Sales Dashboard
An interactive sales dashboard built in **Microsoft Excel** to analyze Adidas sales data.  
It provides insights into total sales, units sold, operating profit, and average margin.  
📊 Key Highlights
- Sales by region and product category  
- Operating profit by retailer  
- Top performing products  
 🛠️ Tools
- Microsoft Excel  
- Pivot Tables & Pivot Charts  
- Data Cleaning & Preparation
